# High-Converting Developer Portfolio — AMOLED Black (#000000)

A high-performance, single-page developer portfolio engineered with **Next.js (App Router)**, **Tailwind CSS**, and **Lucide React**. Tailored for showcasing production-ready MVP delivery, mobile applications, and low-latency audio/real-time systems.

---

## ⚡ Key Features

- **Pure AMOLED Black Theme (`#000000`)**: Designed with high-contrast borders (`border-white/10`), subtle ambient glow accents, glassmorphic cards, and zero dark-gray wash.
- **Section 1 — Hero**: High-converting headline, live terminal diagnostics preview, latency/uptime metrics, and smooth-scroll CTAs.
- **Section 2 — Featured Architecture (Sukoon Audio Engine)**:
  - Simulated interactive 45-second audio engine player with dynamic equalizer bars.
  - High-res mobile device frame displaying room listener sync and 44.1kHz vocal overdub metrics.
  - 4 architectural deep-dive cards with production code snippets and benchmarks:
    - *Direct-to-client stream resolution (bypassing 403 CDN errors)*
    - *Sub-100ms real-time audio sync over MQTT*
    - *Zero UI jank with synchronous MMKV C++ storage*
    - *Hardware-accelerated 44.1kHz vocal overdub recording*
- **Section 3 — What I Build (Services Grid)**:
  - Rapid MVP Development (Idea to Launch in 2 Weeks)
  - Mobile Applications (React Native / Expo / Native Modules)
  - Real-Time & Collaborative Systems (WebSockets, WebRTC, MQTT)
  - SaaS Dashboards & Internal Tooling
- **Section 4 — The 2-Week Delivery Process**:
  - Interactive 6-step roadmap: `01 Scope & Schema` → `02 Interactive UI` → `03 Backend & Integrations` → `04 Automated QA` → `05 Production Deployment` → `06 Handoff`.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 🌐 Deploying to Vercel

This repository is optimized for zero-config Vercel deployment:
1. Push your code to GitHub / GitLab.
2. Import the repository into [Vercel](https://vercel.com).
3. Framework preset: **Next.js**.
4. Click **Deploy**.
